# VibeHub: Responsive Web Design Activity

Welcome to **VibeHub**! 🎧

This project is a small lifestyle and music website created for the **WEDE5020 Responsive Web Design** activities.

The purpose of this project is to help you understand how a website can be changed to work better across different screen sizes.

## 📁 Project Structure

The project contains:

- `index.html` — The structure and content of the website.
- `styles.css` — The CSS used to style the website.

## 💻 Starting Point

The website has been intentionally created as a **non-responsive starting point**.

It looks good on a larger screen, but when the browser becomes smaller, you may notice problems such as:

- Content becoming difficult to view.
- Navigation becoming crowded.
- Sections becoming wider than the screen.
- Cards staying next to each other instead of moving onto new lines.
- Horizontal scrolling being required.

These problems are intentional.

Your task is to investigate **why these problems occur** and then learn how to use CSS to improve the website for smaller screens.

## 🎯 What You Will Learn

During the activity, you will work with concepts such as:

- Responsive Web Design
- Relative values
- Breakpoints
- Media queries
- Flexbox
- Designing for different screen sizes

## 🚀 Getting Started

1. Open `index.html` in your browser. (download folder)
2. Resize the browser window and observe what happens.
3. Identify areas of the website that become difficult to use.
4. Think about how the layout could be improved.
5. Follow the lecturer's code-along to make the website responsive.

## 💡 Remember

Responsive design is not just about making a website smaller.

It is about making sure that the website remains **usable and readable across different screen sizes**.

Have fun experimenting with VibeHub! 🎧
