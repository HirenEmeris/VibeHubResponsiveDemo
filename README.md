# VibeHub — Responsive Design Demo

A small, Gen-Z-style website created for the WEDE5020 Responsive Web Design lecture.

## Teaching purpose

The starter version is intentionally **not responsive**.

It uses **Flexbox**, not CSS Grid.

On desktop:
- The layout looks good.
- Navigation fits in one row.
- Hero content sits beside the feature card.
- Four content cards sit in one row.

When the browser is reduced to mobile:
- The fixed-width sections become wider than the viewport.
- Navigation is squeezed/cut off.
- Hero content becomes difficult to use.
- Cards remain in one long horizontal row.
- Horizontal scrolling is required.

## Suggested live activity

1. Open `index.html` in a browser.
2. Start around 1200px wide.
3. Slowly resize:
   1200 → 1000 → 900 → 800 → 700 → 600 → 500px.
4. Ask students:
   - What changes?
   - Is the website adapting?
   - When does it start becoming difficult to use?
5. Then introduce media queries.
6. Ask students to suggest changes before adding the CSS.

## Important

Do not add the responsive media query until after the class has observed the problem.
